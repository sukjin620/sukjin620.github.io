Microsoft Capstone – Regulatory Readiness Copilot

Microsoft CISO Governance, Risk, and Compliance Team

Weeks to Mins Compliance Gap Analysis
LLM + RAG Compliance Engine

Goal — Reduce the time required to conduct compliance gap analysis from weeks to minutes by building an AI-powered Copilot agent that automatically maps regulatory requirements to Microsoft Security Standards.

My Contributions — Set up an Azure Data Factory pipeline to ingest and process regulatory documents into a RAG index, and configured an Azure AI Foundry agent to perform semantic mapping between Microsoft Security Standards and external regulations using vector search and embeddings.

Team — Collaborated on system architecture with trade-off analysis across design options, jointly designed the confidence scoring system for mapping outputs, and followed Agile sprint planning throughout the project lifecycle.

Takeaways — Technically, I learned how to build production systems with scalability and reliability in mind on Azure infrastructure. Professionally, I developed stronger team collaboration skills and learned to be self-sufficient — exhausting available resources before escalating questions.

Next Steps — Integrate the confidence scoring algorithm directly into the mapping agent pipeline, then collect and iterate on feedback from Microsoft compliance professionals to improve accuracy and coverage.
